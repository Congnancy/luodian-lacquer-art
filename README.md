# 漆艺造物 · 螺钿漆器互动体验

一个本地可运行的中文漆艺展示与交互制作网站。采用 React、TypeScript 与 Vite；首页与器型选择页使用与既有工坊一致的墨绿、漆金、暖白配色，七步工坊继续复用项目原有组件、交互和真实阶段图片。

## 运行

```bash
npm install
npm run dev
```

使用终端输出的本地地址打开网站。生产构建与预览：

```bash
npm run build
npm run preview
```

### 公网访问

项目会通过 GitHub Actions 自动发布到 GitHub Pages：

- 公开网址：<https://congnancy.github.io/luodian-lacquer-art/>
- 将更新推送到 `main` 后，等待 GitHub Actions 中的 **Deploy website to GitHub Pages** workflow 完成，再访问上述地址。
- GitHub Pages 使用 HTTPS，可供其他人直接打开，也满足浏览器摄像头权限的安全上下文要求。首次打开摄像头仍需用户授权。
- `/select`、`/craft`、`/finished` 的刷新与直达路由使用 Pages 404 回退文件处理。
- 本地 `localhost` 仅在本机开发服务器运行期间可用；对外分享请使用上述 HTTPS 地址。

静态托管需将未匹配路径回退至 `index.html`，以支持直接访问或刷新 `/select`、`/craft` 和 `/finished`。

## 流程与路由

- `/`：漆艺知识展示主页，包含章节导航、漆器介绍、材料与工艺内容，页尾提供「开启你的漆艺创作」/「开始选择」入口。
- `/select`：器型与漆色选择。包含几何器型、动物器型、历史文物三类预览。
- `/craft?artifact=black-lacquer-mother-of-pearl-octagonal-bird-flower-plate&lacquer=black`：七步漆黑八方盘制作体验。
- `/finished?artifact=black-lacquer-mother-of-pearl-octagonal-bird-flower-plate&lacquer=black`：完成后的作品展示。

器型和漆色选择及七步制作状态保存在浏览器 `localStorage`，返回选择页、刷新或重新访问合法制作路由时会尽可能恢复。只有黑漆嵌螺钿花鸟纹八方盘的真实工序素材可进入工坊；其他器型可以浏览示意并选择，但确认时会提示素材尚未接入。历史文物保留原页面可选的朱红、漆黑两种颜色，当前工坊仅接入漆黑版本。参数缺失或不合法时会回到选择页并提示重新选择。

## 七道工序与操作

1. 描纹定样：自动绘制纹样。
2. 初髹黑漆：张开手掌左右移动或使用鼠标模拟。
3. 拾贝镶嵌：选择真实贝片素材，拖动并放到对应花位；也支持摄像头捏合操作。
4. 复髹罩漆：模拟覆盖漆层。
5. 拭漆显贝：使用食指移动/画圈或鼠标逐步显露螺钿。
6. 罩清提光：模拟透明罩漆。
7. 磨光成器：画圈或使用鼠标完成抛光。

步骤导航、上一步/下一步、各步骤进度、已放置贝片以及当前器型漆色均会保留。达到最后一步完成条件后进入成品展示，主画面循环播放项目中的 `成品展示.mp4`；成品页提供重新挑战、重新选择器型和返回首页。

## 素材与集成边界

- 七步真实盘面、阶段图、贝片与成品视频均从 `public/craft-images/` 加载。
- 首页「漆器介绍」区域循环播放 `public/artifact-images/home-lacquer-intro.mp4`；静音自动播放并提供真实盘面海报图作为加载/播放前占位。
- 历史文物选择页的 01、02、03、05 卡片图依次使用 `public/artifact-images/relic-01.jpg`、`relic-02.jpg`、`relic-03.jpg`、`relic-05.jpg`；04 保留本地八方盘制作素材。
- 被选中的八方盘使用本地 `/craft-images/步骤3状态0.png` 作为选择预览；工坊复用各工序对应的步骤图片。
- 参考链接 1（Coze）和链接 2（Workbuddy）的项目源码与原始图像素材不在本地工作区。页面 1、2 是基于可读取的公开页面结构自主重建的本地版本，并非原网站源码迁移，也无法保证逐像素复刻。非目标文物缺少原图，选择器使用本地 SVG 器型示意，不冒充馆藏实物照片。
- 本次提供的文物图片以原文件接入。水印/署名信息不会被移除；如需无背景、无水印的版本，请提供你拥有使用授权的透明底原图。
- 首页所需的章节内容为本地整理的漆艺介绍与体验说明。若需精确还原参考页的原文、图片、动画与布局，请提供相应项目源码、可合法使用的图片素材，或清晰页面截图/录屏。
- 摄像头视频和 MediaPipe Hand Landmarker 集成在原工坊中；摄像头能力需在 localhost 或 HTTPS 安全上下文下使用并取得浏览器授权。摄像头无法使用时可切换鼠标模拟；系统不会伪称相机识别成功。
- 成品视频使用可替换的本地媒体元素占位接口，替换 `public/craft-images/成品展示.mp4` 即可更新素材。
- 图片和制作素材均为本地文件；标题字体沿用原有 Google Fonts Noto Serif SC 加载方式，离线时回退到系统中文衬线字体。
